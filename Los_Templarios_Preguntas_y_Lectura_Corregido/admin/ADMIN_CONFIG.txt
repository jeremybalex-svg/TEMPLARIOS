CAMBIA LA CLAVE DEL ADMINISTRADOR

En index.html busca:
const ADMIN_PASSWORD='CAMBIA_ESTA_CLAVE';

y reemplázala por tu clave.

IMPORTANTE: esta clave es solo una barrera de interfaz. Si el proyecto se publica
como HTML estático, cualquier persona técnicamente puede inspeccionar el código.
Para que SOLO tú tengas acceso de verdad al administrador y puedas modificar la
base de datos, hay que conectar el proyecto a un backend con autenticación.

Acceso de administrador:
index.html?admin=1
